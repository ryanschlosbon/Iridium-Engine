# M7.7 directional-shadow receiver bias — 2026-09-12

## Result

The second accepted M7.7 conventional-shadow slice removes severe grazing-angle
self-shadow striping without increasing the global raster bias. Directional
receivers now combine the existing cascade-scaled depth bias with bounded
receiver-plane depth correction and a half-texel geometric-normal world offset.
All three terms are project/profile policy, are exposed in Project Settings, and
are recorded in profiles and capture metadata.

This is an accepted fidelity slice, not M7.7 completion. Independent shadow and
probe visible sets, GPU-scene caster submission, shadow-specific LOD, and the
complete close-contact/thin/alpha/two-sided qualification matrix remain open.

The subsequent directional-caster visibility slice is recorded in
`docs/performance/M7.7-directional-shadow-caster-visibility-2026-09-12.md`.

## Changed behavior and architecture

- `ProjectShadowSettings` owns three directional receiver terms in shadow-texel
  units: 1.25 depth-bias texels, a 2.0-texel receiver-plane correction clamp, and
  a 0.5-texel geometric-normal offset. Their physical size follows the selected
  cascade's reported world-units-per-texel density.
- Each shared shadow consumer supplies world position, shading normal, geometric
  normal, and world-position derivatives. Deferred derives and orients its
  geometric normal from world-position derivatives; complex-forward and probe
  capture preserve the pre-normal-map tangent-frame normal. Normal-map detail
  therefore affects lighting but cannot push the shadow receiver through its
  underlying surface.
- The shader analytically converts world-position derivatives through the active
  cascade transform into a depth gradient over shadow UV. Every raw blocker-depth
  test and every bilinearly reconstructed final comparison evaluates the receiver
  plane at its own sample location. Correction is clamped by the configured
  world-shadow-texel allowance.
- Degenerate or non-finite gradients fail to zero correction. Geometric-normal
  offset is front-facing only and fades with geometric `N·L`; it does not offset
  back-facing receivers.
- Existing D32 storage, four-cascade layout, cache identity, update scheduling,
  raster constant/slope bias, and visibility-one failure remain unchanged. The
  directional shadow UBO remains 720 bytes.
- Validated command-line controls support reproducible A/B runs:
  `--shadow-directional-receiver-bias`,
  `--shadow-directional-receiver-plane-clamp`, and
  `--shadow-directional-normal-offset`.
- Captures now embed the three exact values under `directional_shadow`; profiler
  counters publish integer millionths for lossless automated comparison.

This implements ADR-0010 decision 4. ADR-0008's cache/fallback ownership remains
unchanged; ADR-0010 already supersedes its original receiver-sampling detail, so
no new architecture record is required.

## Controlled cost

The 1280x720 runs used 64 warmup and 64 measured frames with GPU profiling enabled.
This is a shader-cost sanity check, not a native-4K performance-admission set.

| Metric | Bias disabled | Bounded default | Difference |
|---|---:|---:|---:|
| Complete GPU median | 0.189792 ms | 0.187584 ms | -0.002208 ms |
| Deferred lighting median | 0.125952 ms | 0.125952 ms | 0.000000 ms |

Both runs completed all 64 measured frames with zero dropped profile frames. The
small complete-frame difference is normal run variance; no performance win is
claimed. Persistent shadow memory is unchanged.

## Verification and remaining work

- CPU reference tests cover the analytic gradient, per-sample reference adjustment,
  clamping, zero allowance, and degenerate-gradient fail-safe.
- Application configuration tests cover defaults, valid values, usage text, missing
  values, and out-of-range rejection.
- Capture-artifact tests cover exact serialization of all three terms.
- Shared deferred, complex-forward, layered, Weighted OIT, and reflection-probe
  shader consumers compile successfully.
- Historical M5/M6/M7.7 hashes remain frozen behind an explicit
  `m7_7BiasSupersession` chain.
- Full Debug and Release builds compile every shader and target; both pass all
  77/77 CTests. The Release source-free validation runs launch and exit cleanly.

M7.7 still needs independent consumer visibility/submission, shadow-specific LOD
evaluation, position-only caster streams, affected-bounds invalidation, and the
remaining thin/alpha/two-sided/cascade-motion quality matrix before completion.
