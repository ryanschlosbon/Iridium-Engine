# M7.7 shadow consumer-membership cache

Date: 2026-09-29  
Status: implemented; Release runtime smoke qualified

## Outcome

GPU-scene publication now owns camera-independent shadow and reflection-probe
consumer lists. Each list carries a stable nonzero membership revision. Transform,
previous-transform, and world-bounds changes do not revise membership; scene epoch,
enablement, consumer masks, per-instance LOD ceilings, material/bin state, and
referenced geometry products do.

Application extraction consumes the published lists directly instead of scanning
every packed primitive once for shadows and again for probes on every frame.
Directional, spotlight, and point-shadow Vulkan paths use the shadow membership
revision to retain their geometry/material bins, LOD-prefix eligibility, primitive-
to-bin lookup, and sorted candidate layout across transform-only frames. Per-light
and per-cascade visibility/LOD compaction remains device-owned and executes on each
requested shadow refresh.

Cache reuse is additionally keyed by the experimental shadow-LOD texel threshold
and maximum level. A rejected indirect path, backend shutdown, or shadow indirect-
buffer reallocation invalidates the corresponding cache. Direct compatibility
packets remain outside the cached GPU-scene membership.

## Qualification

- Debug engine build: passed.
- `GpuSceneTests`: verifies deterministic publication, exact shadow/probe lists,
  transform/bounds independence, and invalidation for LOD, material, and enablement
  changes.
- M5 contract supersession: passed.
- Release engine launch: passed on the moving eight-instance conventional-shadow
  fixture at 1280x720, with 8 warmup and 16 measured frames.
- Every measured frame reported `1` for directional, spot, and point
  `membership_cache_hit`; all three indirect fallback-reason counters remained `0`.

Smoke telemetry is retained at
`out/benchmarks/m7.7/shadow-membership-cache-smoke.jsonl`.

This checkpoint does not claim a timing admission result from the short smoke run.
It removes redundant host work and exposes durable telemetry for the next warmed
comparison. Position/opacity-only shadow vertex streams remain a separate M7.7
candidate because they alter cooked/runtime geometry storage rather than consumer
membership. No ADR is superseded.
