# M7.7 face-invariant reflection-probe LOD checkpoint

Date: 2026-09-14  
Status: accepted architecture/correctness checkpoint; the 2026-09-24 warmed gate
completed without production admission, so LOD0 remains the global default

## Outcome

Reflection-probe device command generation can now select a resident coarser LOD
independently from the main camera. The experimental policy uses probe position,
capture-face resolution, and the primitive's packed local/world bounds spheres to
bound projected geometric error for a 90-degree cubemap face. The decision is
radial rather than face-projected, so one primitive selects the same geometry on
all six faces and cannot introduce LOD discontinuities at cube seams.

The host limits each candidate to a finest-to-coarsest prefix that is resident and
compatible with its already-bound vertex buffer, index buffer, index type, and
vertex layout. Malformed bounds or chains retain LOD0. Probe LOD has independent
threshold and maximum-level controls; a zero threshold or zero maximum level pins
LOD0. Selection is intentionally stateless for this checkpoint: it avoids multiple
cube-face dispatches racing on one history entry, while the face-invariant rule
already removes cross-face disagreement.

Validation compares the full generated command multiset per face/bin after the
frame fence, including primitive identity, index count/range, and vertex offset.
It also reports device/oracle triangle and reduced-command totals. Production does
not repeat visibility or LOD on the CPU and retains delayed exact device telemetry.

## Qualification

The 1280x720 Debug validation run uses the existing 339-primitive
`m7_three_dense_near_mid_far_v1` cooked fixture, schedules one six-face capture,
and enables a 2-pixel probe threshold.

| Counter | 2 px radial LOD | LOD0 reference |
|---|---:|---:|
| Visible device/oracle commands | 226 / 226 | 226 / 226 |
| Device/oracle triangles | 599,424 / 599,424 | 603,932 / 603,932 |
| Device/oracle reduced commands | 7 / 7 | 0 / 0 |
| Mismatched bins/command regions | 0 / 0 | 0 / 0 |
| Overflow commands | 0 | 0 |

This first content sample removes 4,508 capture triangles (0.75%). The final
scene-linear capture is byte-identical to LOD0 with SHA-256
`ab632c28bc84d485b881e7782b31bbc2336035cea27e76dfa4c46ec0c0881482`.
That image is a correctness result, not a broad visual-admission claim; the fixture
does not strongly expose probe-reflection detail.

The no-validation Release route produces the same 226 commands, 599,424 triangles,
and seven reduced commands while reporting CPU face tests unavailable and all
oracle totals zero. Its capture hash is also identical. Short first-capture timings
remain diagnostic only.

## Follow-up decision

The reflection-sensitive 1024-pixel realtime gate is complete. A 16-pixel bound
preserves byte-identical native-4K final-SDR output but removes only 0.9263% of the
retained capture triangles and produces no repeatable CPU, GPU, wall-time, or
memory win. LOD0 therefore remains the global probe default and radial probe LOD
stays experimental. See
`docs/performance/M7.7-probe-lod-warmed-admission-2026-09-24.md`.
