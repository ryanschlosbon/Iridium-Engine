## Implemented contract

`DepthPyramidProjectionInput/Result` and `projectDepthPyramidBounds` extend the
backend-neutral depth-pyramid reference with world-AABB query construction.
The matrix is explicitly row-major world-to-history-clip, including that view's
actual jitter and Y orientation. The function projects all eight corners using
double intermediates, computes a conservative nearest device depth, rounds it
toward the near plane, and pads outward-rounded pixel bounds by at least one pixel.
Forward/reverse zero-to-one depth and perspective/orthographic matrices are supported.

Stable reasons decline testing for invalid extent/bounds/matrix/settings,
eye/depth-plane intersection, wholly offscreen bounds and small footprints.
Side-plane intersections clamp to the view; depth-plane intersections deliberately
fail visible instead of deriving clipped box extrema. A failed projection never
means invisible. The allocation-free function returns only query eligibility, not
an occlusion verdict. Consumers must separately establish history ownership,
temporal eligibility and valid current bounds before querying the reference/device.
This does not solve disocclusion or moved-occluder history by itself.
