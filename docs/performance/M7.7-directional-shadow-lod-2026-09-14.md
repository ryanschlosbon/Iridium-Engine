# M7.7 directional shadow-map LOD checkpoint

Date: 2026-09-14  
Status: accepted architecture/correctness checkpoint; default remains LOD0 and
warmed visual/performance admission remains open

## Outcome

Directional cascade command construction can now choose geometry independently
from the main camera. The selector converts each cooked LOD's object-space error
to conservative world-space error using the packed local and world bounds-sphere
ratio, then divides by that cascade's measured world-units-per-texel. It selects
the coarsest resident LOD whose error remains within the configured shadow-texel
bound. Near cascades therefore retain more geometry naturally, while lower-density
distant cascades can use coarser geometry without a manually authored distance.

The host admits only the finest-to-coarsest prefix that is resident and compatible
with the vertex buffer, index buffer, index type, and vertex layout already bound
for that command bin. Missing, malformed, non-monotonic, or incompatible chains
fail safe to LOD0. The feature has independent threshold and maximum-level controls:
`--experimental-shadow-lod-error-texels` and `--shadow-lod-max-level`. A zero
threshold or zero maximum level pins LOD0, which remains the global default.

The GPU compute pass makes the final per-cascade decision. Validation repeats the
density selector independently on the CPU after visibility and compares complete
per-bin command multisets after the frame fence: primitive identity, index count,
first index, vertex offset, and instance count. Production performs neither CPU
light-view visibility nor CPU shadow-LOD selection and retains delayed exact device
command/triangle telemetry.

## Remaining gate

LOD0 remains the global directional-shadow default. Admission needs matched native-
4K threshold sweeps on foliage, alpha-clipped silhouettes, thin casters, long
shadows, cascade transitions, and moving/static heterogeneous scenes. Point-cube
LOD is covered by the later face-invariant radial checkpoint; spotlight projection
remains open. Position-only shadow streams and static membership caching also remain
candidates only after measured benefit.
