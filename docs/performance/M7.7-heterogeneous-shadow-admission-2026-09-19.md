# M7.7 heterogeneous shadow-command admission

Date: 2026-09-19  
Status: accepted for production device-command submission; shadow LOD remains
default-off pending its separate visual threshold gate

## Outcome

Directional cascades, spot-atlas tiles, and point-cube faces are admitted together
on the automatic GPU-scene command path. A new qualification-only
`--reference-direct-shadows` control selects conventional direct shadow draws while
leaving the main GBuffer and reflection-probe routes automatic. This makes the A/B
specific to shadow command construction; the older `--reference-direct-gbuffer`
umbrella remains available and retains its previous behavior.

The frozen fixture moves 32 instances (96 opaque primitives) under one Ultra
directional light, two High spotlights, and two High point lights. It warms for 120
frames and measures 600 native-4K frames. Motion invalidates the shadow caches so
the comparison covers continuous heterogeneous refresh rather than a cached idle
interval.

The combined feature set also exposed profiler counter truncation: a feature-heavy
frame emits 310 counters while the fixed capacity was 288. The bounded capacity is
now 320, retaining every delayed device count and overflow result without adding
steady-frame allocation.

## Correctness

The validation-enabled Debug oracle run retained all counters and reported:

| Consumer | Tested / culled | Device / CPU-oracle commands | Mismatched bins | Overflow | Direct fallback |
|---|---:|---:|---:|---:|---:|
| Directional cascades | 288 / 90 | 198 / 198 | 0 | 0 | 0 |
| Spot tiles | 192 / 0 | 192 / 192 | 0 | 0 | 0 |
| Point faces | 1,152 / 705 | 447 / 447 | 0 | 0 | 0 |

Release retains exact delayed device counts without the CPU oracle. Across the
512-frame detail ring, directional and spot output remain 198 and 192 commands;
point output varies from 447 to 468 as moving bounds cross cube faces. Every
retained overflow counter is zero.

The matched frame-300 final-SDR captures are byte-identical with SHA-256
`01866a24291d062a63e12aa11906af50e3dcaec93c16e25f2a599e9a4805ad90`.
Both routes report identical requested/committed memory, allocation count, and
peak memory because the bounded command storage is persistent by design.

## Native-4K performance

Two 120-warmup/600-measured pairs ran in A/B then B/A order on the reference RTX
4090 system. Values below are median milliseconds; automatic GPU shadow totals
include compaction plus graphics.

| Metric | Automatic A | Direct A | Automatic B | Direct B |
|---|---:|---:|---:|---:|
| CPU directional record | 0.0366 | 0.0987 | 0.0338 | 0.0986 |
| CPU spot record | 0.0227 | 0.0873 | 0.0223 | 0.0877 |
| CPU point record | 0.0654 | 0.2310 | 0.0653 | 0.2313 |
| **CPU shadow record total** | **0.1247** | **0.4170** | **0.1214** | **0.4176** |
| GPU directional total | 0.0340 | 0.0282 | 0.0339 | 0.0289 |
| GPU spot total | 0.0216 | 0.0205 | 0.0205 | 0.0205 |
| GPU point total | 0.0430 | 0.0584 | 0.0429 | 0.0584 |
| **GPU shadow total** | **0.0986** | **0.1071** | **0.0973** | **0.1078** |
| CPU complete frame | 3.8311 | 3.8394 | 3.7944 | 3.8393 |
| GPU complete frame | 3.0988 | 3.1022 | 3.0951 | 3.1072 |

Automatic submission reduces median CPU shadow recording by 0.2923-0.2962 ms
(70.1-70.9%). Its combined GPU shadow work is also 0.0085-0.0105 ms lower despite
paying three compact dispatches. Whole-frame medians improve slightly in both
orders; tails remain dominated by unrelated 4K work, so no broader frame-time
claim is made from this fixture.

This closes the warmed heterogeneous admission gate for conventional shadow
device-command submission. It does not enable the experimental shadow LOD
threshold globally. Thin/alpha-clipped silhouette and transition sweeps remain
required before changing the LOD0 default. Position/opacity-only streams, static
membership caching, and larger light/primitive capacity-residency sweeps remain
independent optimization work.
