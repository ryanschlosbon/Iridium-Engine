# M5.6 Stabilized Directional Shadows

Accepted 2026-08-09 on the reference RTX 4090/Core i9-14900K system.

## Changed behavior and architecture

One authored shadow-casting directional light is selected by priority then stable
entity UUID. It owns four stabilized cascades in a persistent 2048x2048 D32 array.
The backend-neutral frame packet carries ownership, transforms, and update/sample
masks; the production graph declares the array as an imported external resource,
while Vulkan owns its persistent image, per-layer views, render passes, pipelines,
compare sampler, descriptors, and transitions.

Splits use practical/log lambda 0.7. Exact frustum corners, a 5% guard band, 100 m
depth padding, 1/16 m radius quantization, and light-space texel snapping stabilize
the projections. The last 10% of each cascade blends into the next published layer.
Deferred and complex forward share one shadow sampler: clamp-to-white
`LESS_OR_EQUAL`, 5x5 tent PCF, slope/constant raster bias, angle-aware receiver
depth bias, and a one-shadow-texel world-normal offset.

The caster path accepts opaque and forward-opaque packets. It has distinct opaque
and alpha-mask, one- and two-sided pipelines. Alpha masking reads the same indexed
material opacity contract as surface shading. General transparent casters remain
unsupported. Cache validity includes light owner/revision, stabilized matrix,
caster revision, and pipeline revision. Dirty unscheduled projections are never
sampled; omitted directional lights remain deterministically unshadowed.

## Visual and validation evidence

The final validation-enabled 1280x720 fixture contains a two-sided receiver, a
one-sided warm blocker, and a duplicate fully clipped alpha-mask primitive. The
real blocker casts the expected directionally offset contact shadow with a filtered
edge. The clipped oracle produces neither visible geometry nor a phantom shadow.
Adding that oracle leaves final SDR byte-identical, while the profile records four
alpha-mask shadow draws during a four-cascade refresh.

The accepted image SHA-256 is
`2fcfa1ff658f96e76bb3b804a4b203074526deb0ad08601437858e736d5fccf6`.
Relative to the initial directional candidate, final stabilization/bias changes are
localized to 0.3316% of pixels with 0.999494 mean luma SSIM. Cascade and visibility
debug views expose published selection and compare results. Vulkan validation is
clean, and capture metadata records owner UUID, light slot, D32 format, resolution,
four cascades, sampleable mask 15, and the 5x5 filter.

## 4K performance and memory

Release measurements use 64 warmups and 64 measured frames. Times are median / p95
in milliseconds.

| Path/range | Time | Observed work |
|---|---:|---:|
| Static cache hit, full GPU frame | 0.654 / 0.995 | 4 cached, 0 updated |
| Moving caster, full GPU frame | 0.669 / 1.022 | 4 dirty, 4 updated |
| Four-cascade directional pass | 0.0171 / 0.0177 | 12 draws, 4 alpha-mask |
| CPU directional recording | 0.0216 / 0.0271 | four layers |
| Deferred direct + IBL + shadow sampling, static | 0.272 / 0.613 | 5x5 PCF |

Static measured frames correctly contain no directional GPU/CPU pass. The moving
fixture invalidates and refreshes all four cascades every frame. Both 64-frame runs
drop zero frames. The 0.0177 ms refresh p95 is far below the provisional 1.5 ms
scheduled-shadow gate; complete deferred lighting including shadow sampling remains
inside the 1.4 ms direct-light-plus-IBL envelope.

The persistent `image.shadow.directional` allocation is exactly 67,108,864 bytes
(64 MiB) requested and committed. Because it is imported external history, adding
the graph declaration changes no physical graph slot: SDR remains 18 slots with 20
passes and 22 logical resources.

## Remaining risks and deferrals

- Only one directional light owns shadows. Additional directionals are diagnosed
  and remain unshadowed.
- D16 is still a measured future production option; D32 is the accepted reference.
- The current CPU packet caster queue conservatively treats opaque surfaces as
  potential casters. M7 can replace this with GPU-scene visibility without changing
  the RHI cache-validity contract.
- General transparent, colored, transmissive, and clipmap shadows are deferred.
- M5.7 owns stable spot-atlas and point-cube allocation, caching, budgets, and seams.

ADR-0008 is accepted with this evidence. No existing ADR is superseded. M5.7 is
next.
