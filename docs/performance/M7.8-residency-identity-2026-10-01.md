# M7.8 lossless residency identity and checked request conversion

Date: 2026-10-01
Status: residency metadata prerequisite; GPU allocation remains unimplemented

## Contract and implementation

RHI `VirtualShadowMap.h/.cpp` introduces a separate residency ABI v1. Its 48-byte
aligned key preserves all 128 UUID bits, both signed 64-bit world-page coordinates,
the full 64-bit projection revision, mip, level/face and projection kind. UUID bytes
are assembled explicitly into little-endian words; 64-bit values use low/high words
without requiring shader int64. A key is never reduced to a collision-prone hash
or camera-window index. ABI zero denotes unused storage, not a valid identity.

The 96-byte aligned resident record adds independent full-width static/dynamic
caster revisions, last-use/render frame serials, physical slot, signed priority,
layer validity and a zero reserved word. Sizes and relevant std430 offsets are
compile-time checked. Checked pack/unpack functions reject unsupported owner IDs,
zero projection revisions, unknown projections, invalid point faces/nonzero spot
faces, invalid physical capacity/slots, unknown layer bits, nonzero reserved data
and empty/incompatible ABI records. A zero validity mask remains legitimate pending
content; packing does not mark it raster-complete or sampleable.

`unpackDirectionalVirtualShadowGpuRequest` converts a compact marking ABI-v2 request
using its exact frame-slot clip snapshot. It checks the selected clip, power-of-two
page size/divisible resolution, page window, level/mip, priority/layers and nonzero
coverage before recovering the full owner and projection/caster revisions. The
Vulkan retired-slot collector now uses this shared conversion rather than a private
subset of metadata checks; its full-depth CPU oracle compares full identities and
both caster revisions in addition to coverage and policy.

The compact request does not independently carry owner/revisions. The caller must
pair it with the immutable snapshot from the submitting slot; this conversion
cannot authenticate an arbitrary unrelated snapshot with identical numeric fields.
The existing fence-scoped backend pairing supplies that ownership. Future GPU
residency must upload equivalent identity metadata and compare full keys itself.
The qualification bridge must not become a CPU readback-driven production allocator.

No GPU table/record storage is allocated, initialized or reinterpreted yet. Existing
flat uint page-table storage remains an allocation checkpoint, not an array of the
new records. Marking ABI v2, asset serialization, shaders, dispatches and physical
storage sizes remain unchanged. Independent static/dynamic physical depth storage
and residency completion/generation publication remain subsequent work.

## Verification and impact

- Debug/Release builds succeed. The RHI suite expands from 20 to 23 tests and
  passes in both configurations. Tests cover exact UUID words, signed extrema and
  negative/high coordinates, full-width revisions/frame ages, negative priority,
  independent/zero validity, malformed/empty ABI data, physical bounds and invalid
  projection/face/layer fields. Request tests reject unpublished clips, out-of-window
  pages, zero coverage and mismatched policy fields.
- All 78 CTest tests pass in both configurations, including the refreshed latest
  fixture fingerprint gate.
- Native-4K Debug with Vulkan validation and the full-depth CPU oracle completes
  eight moving-camera frames. Both slots match their recovered identity/revisions
  and coverage exactly; final pending slots are collected on shutdown. Validation
  error log is empty. Artifacts: `out/m7_8_residency_identity_20261001.*`.
- There is no additional GPU allocation or changed image-producing work. This
  prerequisite makes no new visual/performance admission claim. Added qualification
  CPU conversion cost is not yet independently benchmarked; the previous live-depth
  performance/p99 gate remains authoritative.

M7.8 remains active and no accepted ADR is superseded. Next implement GPU metadata
upload/lookup, bounded allocation/eviction and generation-safe completion using
these full keys, then connect page raster and sampling. Remaining M7.9-M7.12 gates
are unchanged; M7 is not complete.
