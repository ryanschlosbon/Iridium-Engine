# M7.6 live scene-depth readback parity — 2026-09-10

## Result

The opt-in depth build now has a one-shot live-source validation route. The command
line `--validate-depth-pyramid-capture` enables the experimental build, copies the
actual D32 opaque scene depth and every R32 pyramid mip to fence-scoped host-visible
storage, and compares every result against `DepthPyramidReference` after completion.
It does not enable occlusion rejection and has no production readback cost.

The validation render-graph hook is ordered after the build/ready passes and before
sorted transparency. It declares transfer-source usage for scene depth and the
pyramid; when no validation is requested the backend skips the hook. Readback
buffers are attached to the producing frame context and are inspected only after
that context's fence signals. Explicit collection can wait for all pending frames at
bounded-run shutdown. Resize/rebuild cannot destroy a pending buffer; backend cleanup
destroys any uncollected buffer only after device/frame idleness.

Comparison is bit-exact because farthest-depth reduction selects an existing float
without arithmetic. The result reports source/pyramid texel counts, invalid source
depths, mismatches, first mismatch and maximum finite absolute error. Invalid D32
values or any mismatch fail the run.

## Evidence

- Debug empty editor, 1280x720: 921,600 live source texels and 1,228,763 pyramid
  texels across 11 mips; zero invalid source values, zero mismatches.
- Release populated `m7_three_dense_all_visible_v1`, decorated-window odd extent
  3840x2139: 8,213,760 live source texels and 10,949,495 pyramid texels across
  12 mips; zero invalid source values, zero mismatches and zero maximum error.
- Both runs use Vulkan validation plus synchronization validation and process-local
  suppression of unrelated broken implicit overlay layers. No Vulkan errors occur.
- Experimental build without a readback request completes normally, proving the
  graph hook skip path.
- Debug and Release engine builds succeed. Portable CTest suites pass 77/77 in both;
  graph tests cover transfer-source capability and pass ordering, and CLI tests
  cover implicit build enablement and help discovery.

Relevant interfaces are the backend-neutral
`DepthPyramidCaptureValidationResult`, RHI request/collection methods, the Vulkan
fence-scoped readback implementation, application validation reporting, and the
optional graph hook. No material, scene, or GPU-scene ABI changed. No accepted ADR
changed, and M7.6 remains active.
