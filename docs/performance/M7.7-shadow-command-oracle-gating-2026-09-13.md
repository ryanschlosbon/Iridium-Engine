# M7.7 shadow-command oracle gating — 2026-09-13

## Result

Device-built directional, spot, and point shadow commands no longer depend on
repeating every light-view visibility test on the CPU in production. Exact device
counts and overflow checks remain fence-delayed and available to profiling. The
independent expected-count comparison is now qualification-only: validation builds
enable it automatically, and `--shadow-indirect-qualification-oracle` can enable it
without Vulkan validation.

This removes the CPU light-view matrix from the normal GPU-scene path. CPU
visibility remains necessary for explicit direct/mixed fallback casters. Candidate
resolution and physical-buffer bin construction are still host-side and are the
next caching/device-ownership opportunity.

## Contract

- `RenderBackendConfig::enableShadowIndirectQualificationOracle` owns the backend-
  neutral switch; the Vulkan backend does not infer editor or command-line state.
- Pending count readback stores output capacities regardless of oracle state. It
  always reports device commands and overflow, but only allocates expected counts,
  accumulates mismatches, and throws oracle disagreement when qualification is on.
- Profiles distinguish `qualification_oracle` from `oracle_commands`. A disabled
  oracle reports zero CPU tests/culled casters for wholly GPU-owned submissions,
  while delayed `device_commands` remains exact.
- Capture metadata records the effective switch, including validation's automatic
  qualification behavior.
- `--reference-direct-gbuffer` remains the direct image reference and does not
  silently enable the oracle.

## Evidence

The 35 m directional moving-grid run used 8 warmups and 16 measured frames at
1280x720 Release with validation off. It retained 30 device commands per measured
frame, zero CPU oracle commands/tests, zero overflow, and the accepted final-SDR
SHA-256 `fcb0152562a944a04a64a1d7b2dafc2d0ea62bd19196dca81b5e3ffa00a5bd07`.
Directional CPU shadow recording measured 0.0268 ms median / 0.0317 ms p95;
compaction and graphics measured 0.0072 ms and 0.014432 ms median. This is a focused
qualification, not the heterogeneous M7.7 scale gate.

## Remaining gate

Warmed heterogeneous spot/point fixtures still need repeated refreshes rather than
one cache-fill frame. Host candidate binning should be cached by stable GPU-scene
geometry/material membership, and shadow-specific LOD/position-opacity streams and
reflection-capture visibility remain active M7.7 work. No ADR is superseded.
