# M7.7 face-invariant point-shadow LOD checkpoint

Date: 2026-09-14  
Status: accepted architecture/correctness checkpoint; default remains LOD0 and
warmed visual/performance admission remains open

## Outcome

Point-cube device command construction now selects geometry independently from the
main camera and directional cascades. The selector uses the point-light position,
cube-face resolution, and the primitive's packed local/world bounds spheres to
bound projected geometric error for a 90-degree face. The decision is radial and
therefore identical across all six faces; cube seams cannot receive conflicting
LOD choices.

The host exposes only the resident finest-to-coarsest prefix compatible with the
already-bound vertex buffer, index buffer, index type, and vertex layout. Invalid
bounds, malformed chains, a light inside conservative instance bounds, or missing
compatible children retain LOD0. Point shadows share the experimental shadow-texel
threshold and maximum-level controls with directional shadows. Zero threshold or
zero maximum level pins LOD0, which remains the global default.

Validation now compares complete per-face/bin command multisets after the frame
fence, including primitive identity, index count/range, vertex offset, and instance
count. It also reports device/oracle triangle and reduced-command totals. Production
does not repeat GPU-owned point-face visibility or LOD selection on the CPU.

## Qualification

The new `m7_point_shadow_lod_near_mid_far_v1` fixture uses three instances of the
frozen dense Alfa asset, its resident cooked LOD artifact, and one High-quality
512-pixel point cube. Both 1280x720 Debug runs use Vulkan validation. The
experimental run uses a 2-shadow-texel bound.

| Counter | 2 texel radial LOD | LOD0 reference |
|---|---:|---:|
| Visible device/oracle commands | 565 / 565 | 565 / 565 |
| Device/oracle triangles | 1,498,394 / 1,498,394 | 1,509,830 / 1,509,830 |
| Device/oracle reduced commands | 16 / 16 | 0 / 0 |
| Mismatched bins/command regions | 0 / 0 | 0 / 0 |
| Overflow commands | 0 | 0 |

The selector removes 11,436 point-shadow triangles (0.7574%). Scene-linear output
is numerically equivalent rather than byte-identical: maximum absolute AP1
difference is `5.96046448e-7`, mean absolute difference is `4.7428462e-13`, and
no pixel differs by more than `1e-6`. The different file hashes are therefore not
treated as a visible regression.

The no-validation Release route emits the same 565 commands, 1,498,394 triangles,
and 16 reduced commands while reporting zero CPU point-caster tests and zero oracle
commands/triangles. Its capture matches the experimental Debug hash. Short first-
update timings remain diagnostic only.

## Remaining gate

LOD0 remains the global point-shadow default. Admission needs native-4K threshold
sweeps with thin and alpha-clipped silhouettes, lights near conservative bounds,
moving lights/casters, cache refreshes, and multiple resolutions. Spotlight LOD
is covered by the later authored-projection checkpoint; its perspective cone uses
a conservative clip-space bound rather than the cubemap radial approximation.
