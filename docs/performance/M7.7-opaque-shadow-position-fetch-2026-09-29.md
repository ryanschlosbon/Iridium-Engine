# M7.7 opaque-shadow position-only fetch

Date: 2026-09-29  
Status: accepted for production conventional shadows

## Outcome

Opaque directional, spotlight, and point-shadow pipelines now expose only the
position attribute to Vulkan and use vertex shaders that consume only position.
This applies to both direct compatibility draws and GPU-scene indirect commands.
Alpha-masked casters retain the canonical position, vertex-color, UV0, and UV1
inputs required for exact opacity evaluation.

The retained design uses the existing interleaved 72-byte canonical vertex store.
It reduces opaque shadow vertex fetch without duplicating every position into a
second persistent buffer, adding a cooker section, or splitting GPU-scene geometry
identity. A physically compact 12-byte position stream is therefore not admitted:
it would increase persistent geometry memory and publication complexity, and must
show an additional complete-frame benefit before reconsideration.

## Correctness

- All six direct/GPU-scene opaque vertex shaders compile successfully.
- Validation-enabled Debug exercised moving directional, spot, and point shadows
  with the exact indirect-command oracle for 8 measured frames and exited cleanly.
- A native-4K frame-150 final-SDR capture is byte-identical between the previous
  full-attribute path and the position-only path (matching SHA-256
  `15ce9f9b872adc3262d7796a6c70da11e42bf5538249ec31334059e070738073`).
- The architecture regression test requires opaque shaders to declare position
  only and requires masked pipelines to retain the four-attribute layout.

## Native-4K Release A/B

The moving eight-instance conventional-shadow fixture ran two reversed-order
60-warmup/300-measured pairs with Vulkan timestamps enabled.

| Metric | Full fetch A | Position only A | Position only B | Full fetch B |
|---|---:|---:|---:|---:|
| Wall average (ms) | 11.499817 | 11.415609 | 11.284736 | 11.520362 |
| CPU frame median (ms) | 11.2867 | 11.23035 | 11.1162 | 11.3615 |
| GPU frame median (ms) | 5.752176 | 5.786176 | 5.485424 | 5.891472 |
| Combined shadow raster median (ms) | 0.929824 | 0.847584 | 0.843536 | 0.932000 |

The isolated conventional-shadow raster saving repeats in both orders:
`0.082240 ms` and `0.088464 ms`, approximately 8.8-9.5%. Spotlight gains are
small because its workload is less vertex-heavy; directional and point-cube work
account for most of the repeatable reduction. CPU recording is effectively
unchanged, as expected for a pipeline/input-layout optimization.

## Evidence and decision

Telemetry and matched captures are under
`out/benchmarks/m7.7/shadow-position-fetch-*.jsonl` and the corresponding capture
directories. Retain the attribute-minimal implementation as the production
conventional-shadow path. Do not add duplicated compact position storage without a
new memory-inclusive admission gate. No ADR is superseded.
