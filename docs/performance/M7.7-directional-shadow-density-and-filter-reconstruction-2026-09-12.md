# M7.7 directional-shadow density and filter reconstruction — 2026-09-12

## Result

The first M7.7 conventional-shadow slice fixes the two causes most directly
associated with the owner-observed stepped directional penumbrae. Directional
coverage no longer expands implicitly to an arbitrarily distant camera far plane,
and PCSS filter taps now reconstruct the four neighboring depth comparisons before
interpolation. The raw-depth blocker search remains unchanged.

This is an accepted implementation slice, not M7.7 completion. Independent
shadow/probe visible sets, GPU-scene caster identities, receiver-plane bias, and
the broader grazing/thin/alpha-caster qualification matrix remain open.

The subsequent accepted receiver-bias slice closes the receiver-plane/grazing
item with bounded project policy and matched validation evidence; see
`docs/performance/M7.7-directional-shadow-receiver-bias-2026-09-12.md`.

## Changed behavior and architecture

- `ProjectShadowSettings::directionalMaximumDistanceMeters` defaults to 250 m and
  is editable in Project Settings. The active camera may shorten that distance,
  but its far plane can no longer silently expand coverage and dilute every
  cascade. A validated `--shadow-directional-distance` override supports exact
  fixtures and workload profiles.
- The existing engine-derived practical/logarithmic split remains the production
  policy (`lambda = 0.85` by default). Artists do not author four brittle cascade
  planes. Each cascade continues to use a stabilized world-units-per-texel scale.
- Exact per-frame counters report effective coverage, every split far distance,
  and every cascade's world units per texel in integer millionths.
- PCSS retains raw depth for blocker detection. Its final disk filter now performs
  bilinear reconstruction over binary depth comparisons at every tap, preventing
  a nearest-depth texel staircase from merely being spread across a wider
  penumbra.
- Receivers beyond the configured last split are explicitly unshadowed; the
  cascade debug view follows the same cutoff.
- A project Cinematic profile is now reachable for an Ultra-authored light:
  32 blocker samples and 64 filter samples. Lower per-light tiers still cap the
  project profile, preserving per-light cost control.

Raster and receiver bias constants were deliberately not increased. Existing
receiver offset remains scaled by each cascade's world texel footprint. Coverage
and filter reconstruction address density and quantization; masking them with a
larger global bias would trade the staircase for peter-panning. Receiver-plane
depth-gradient bias and a bounded geometric-normal offset remain the next bias
qualification slice.

## Native-4K cost

Release, hidden 3840x2160 runs used 100 warmups and 500 measured frames. The only
intentional difference is PCSS versus fixed PCF; both retain the same scene,
coverage, 4096² shadow storage, source asset, and renderer.

| Metric | Fixed PCF | Ultra PCSS | Difference |
|---|---:|---:|---:|
| Complete GPU median | 1.232352 ms | 2.509856 ms | +1.277504 ms |
| Deferred lighting median | 0.456704 ms | 1.131520 ms | +0.674816 ms |
| CPU frame median | 9.0625 ms | 10.0456 ms | +0.9831 ms |

The observed p95 ranges contain common approximately 10 ms GPU stalls in both
runs and are not used to claim a filter-specific tail result. The measured PCSS
median remains below the existing 1.4 ms complete deferred-lighting envelope on
the reference RTX 4090, but its cost is material. Fixed PCF remains a selectable
performance policy; PCSS is the high-fidelity contact-hardening policy rather than
an unconditional low-cost default for every workload.

## Verification and remaining work

- Focused Release shader compilation and the directional-shadow, application-
  configuration, and CPU-profiler tests pass.
- A current source-free cooked artifact launches the engine successfully for both
  validation and native-4K performance runs.
- Full Debug and Release builds compile every shader and target; both pass all
  77/77 CTests. The historical M5 hashes remain frozen behind an explicit M7.7
  shader/contract supersession rather than being silently rewritten.
- Independent caster visibility/submission, position-only streams, shadow LOD, and
  the remaining thin/alpha/two-sided/cascade-motion M7.7 matrix remain open. The
  subsequent receiver-bias report closes the grazing receiver-plane item.

No accepted ADR is changed. The slice implements the conventional-CSM fidelity
order already recorded in the M7 plan and preserves CSM as the production/reference
and future sparse-shadow fallback.
