# M7.8 full-view depth page-demand accumulation

Date: 2026-09-30
Status: qualified experimental compute checkpoint; M7.8 remains active

## Behavior and ownership

The previous region producer retains its exact 65,536-receiver bound. The new
full-view producer instead reconstructs every source depth pixel and atomically
accumulates its coverage into a dense, bounded grid of virtual page cells. It
chooses the finest eligible clip with the same guard-band/coarse fallback rules
as the CPU oracle. No spatial subsampling, pixel-sized receiver array, spin-lock,
or per-region compaction is required. The existing hierarchical compactor runs
once over the cells, preserving stable signed world-page coordinates and ABI v2.

The RHI `buildVirtualShadowFullViewPageGrid` validates clip coherence, independent
grid offsets, total cell capacity and signed GPU address range. With the current
65,536-cell workspace, one 256x256-page clip or four 128x128-page clips fit.
Oversized stacks fail explicitly; arbitrary resolutions/clip counts are not
admitted. Clip pages have the configured interior page size (currently 128 texels).
This is bounded scratch indexing, not a change to sparse residency identity.

`VulkanVirtualShadowFullViewPass` owns immutable per-slot storage descriptors,
depth bindings, pipeline and cleanup. The caller must retire a slot before changing
its depth binding, upload matching packed clips, and supply depth layout/producer
dependencies. Recording initializes every active cell, scans all pixels through
a two-dimensional dispatch, and publishes writes to
`VulkanVirtualShadowMarkingPass::recordCompaction`. Clear/invalid depth, singular
homogeneous reconstruction and out-of-clip pixels do not contribute requests.
One source pixel contributes one coverage sample; source pixel count is bounded
to uint32 range. The CPU grid helper currently performs bounded host validation
and builds its small offset vector; CPU recording cost is not yet qualified.

The persistent resource owner initializes the pass only under
`--experimental-virtual-shadow-resources`. No extra tracked buffers or images:
the pass reuses the existing raw-mark range. Resource memory remains 93,064,256
bytes (88.753 MiB) across the pool, page table and two working sets. Pipeline and
descriptor driver allocations are not included in this buffer/image counter.

## Verification and measured cost

RTX 4090, i9-14900K, MSVC, D32 input, Vulkan synchronization validation:

- CPU contracts: 15/15 cases pass, including signed origins, scroll-stable cell
  count, independent offsets, oversized grids and GPU coordinate overflow rejection.
- Hardware requests and unique/output/overflow/dropped-coverage telemetry exactly
  match the CPU reference for 67x65 full-view pixels with two clips, independent
  origins and finest guard fallback, and 3840x2160 (8,294,400) pixels with the
  maximum 65,536-cell single clip. Output capacity is deliberately 32 requests,
  exercising bounded overflow and priority ordering rather than hiding truncation.
- Both configurations check forward/reverse clear endpoints, nonfinite and
  out-of-range depth, translated/perspective reconstruction, and singular-camera
  empty output after populated work. Five subsequent populated iterations verify
  reuse after the empty frame. Existing region and two-slot mark/compact tests pass.
- Five warm GPU timestamp samples cover cell initialization, all-pixel accumulation
  and complete compaction, excluding upload/readback and pipeline initialization.
  Native 4K median: **0.569824 ms Debug / 0.569504 ms Release**. The two-clip odd
  fixture measures 0.126272 / 0.113248 ms. These are standalone synthetic costs,
  not whole-frame improvements or representative clip-stack production admission.
- Full Debug/Release builds succeed and all 78 repository tests pass in each
  configuration, including the updated M5 current-contract fingerprint gate.
- An eight-frame Debug engine launch at 1280x720 with validation and experimental
  resources exits zero with an empty error log. Average short-run CPU frame time
  is 5.758825 ms; this is lifecycle evidence, not a matched performance comparison.
  Local artifacts: `out/m7_8_full_view_profile_20260930.jsonl` and corresponding
  `m7_8_full_view_startup_20260930.log/.err`.

## Remaining gate

Normal scene frames still do not dispatch the producer. Conventional shadows
remain unchanged, so this checkpoint makes no visual-quality claim. Next publish
stable live directional clips and schedule the full-view producer plus compaction
in the render graph with per-slot ownership and explicit depth dependencies.
Qualify camera motion, clip scrolling, resize, overlapping slots and native-4K
whole-frame timings before promotion. Atomic contention and multi-clip cost must
be measured on representative scenes. Forward/transparency receivers require an
explicit coverage producer or conventional fallback; opaque depth is not enough.
Page residency/cache updates, page rasterization and virtual sampling remain
later M7.8 work. No accepted ADR is superseded and M7.8 is not complete.
