# M6.7 WeightedOIT instance-stream qualification — 2026-08-25

## Outcome

The 4,096- and 65,536-particle high-overdraw Debug/Vulkan-validation tiers now use
one runtime ECS entity, one transparent packet, and one Vulkan instanced draw per
fixture. The backend-neutral forward submission carries a bounded `glm::mat4`
transform span; `DrawPacket` references it with an eight-byte range that reuses the
packet's existing tail padding, so the packet remains exactly 240 bytes.

The runtime-only `RenderInstanceBatchComponent` owns local transforms and cached
aggregate bounds per submesh. It is intentionally not part of source/cooked scene
serialization or editor authoring. Opaque, SortedSurface, selection, and animated
batch support remain deferred; current batch publication is restricted to classified
WeightedOIT content whose topology is prewarmed.

## Reference-system Debug validation

All measurements used an RTX 4090 at 1280x720 with Vulkan validation active and a
hidden window. Debug timing is diagnostic rather than Release acceptance evidence.

| Tier | Entities / packets / draws | Upload | Scene build | CPU extract | Transparent sort | CPU forward record | GPU OIT accumulate |
|---|---:|---:|---:|---:|---:|---:|---:|
| 4,096 / 16 depth layers | 1 / 1 / 1 | 262,144 B | 14.502 ms | 5.082 ms | 0.0009 ms | 0.163 ms | 1.341 ms |
| 65,536 / 64 depth layers | 1 / 1 / 1 | 4,194,304 B | 220.780 ms | 0.261 ms | 0.0009 ms | 0.607 ms | 7.447 ms |

The 4,096 measurement predates the identity-parent bulk-copy optimization; it is
retained as conservative evidence. At 65,536, extraction improved from 567.681 ms
with one ECS entity/packet per particle to 0.261 ms with the instance stream, while
transparent sorting improved from 389.941 ms to 0.0009 ms. The intended fragment
work remains visible in the 7.447 ms Debug accumulation time.

Both tiers report exact instance/upload counters, zero SortedSurface fallback, zero
capacity fallback, and no profiler overflow. The stream cap is 65,536 transforms or
4 MiB per frame context; the two buffers are resident only with WeightedOIT topology.

## Image validation

The 65,536 scene-linear PFM contains 2,764,800 finite channel values, zero nonfinite
values, and 165,256 active pixels. Against the earlier 65,536-explicit-packet
capture, the instanced result has maximum absolute AP1 error 0.03125, RMSE
0.0003477514, p99 absolute error 0, and maximum relative error with a `1e-4` floor
of 0.00292612. Those values remain inside the frozen draw-order thresholds of
0.0625 absolute, 0.002 RMSE, and 0.005 relative.
