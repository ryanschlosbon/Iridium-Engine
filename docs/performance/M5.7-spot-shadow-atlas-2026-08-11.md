# M5.7 Persistent Spot-Shadow Atlas Checkpoint — 2026-08-11

Status: first spot-shadow GPU vertical slice implemented and validated. Point cubes
and caster culling subsequently landed; final complex-forward and multi-process
M5.7 acceptance remain.

## Behavior and architecture

- Spot lights use the existing priority/quality/contribution/UUID request ordering,
  stable guarded allocator, and rendered-texel cache scheduler. The application owns
  allocation and cache policy; Vulkan owns only the persistent D32 image, pipelines,
  frame data, and raster commands.
- The persistent square atlas is 4096 by default (64 MiB D32) and is startup
  configurable to 2048, 4096, or 8192 with
  `--shadow-spot-atlas-resolution`. The 256-entry shadow-data table covers every
  512 tile in the maximum 8192 atlas.
- Each sampleable spot publishes its shadow-data slot into the existing packed GPU
  light record before clustered lighting uploads it. Deferred and complex-forward
  consumers therefore perform constant-time per-light lookup and call the same
  guarded 5x5 comparison sampler.
- Updated tiles clear their complete allocation, including a four-texel guard, then
  rasterize only the inner region. Cached tiles retain their contents. Alpha-masked
  and double-sided caster variants reuse the canonical material descriptor contract.
- Extracted submesh spheres are transformed conservatively for non-uniform scale.
  Updated tiles reject only casters proven outside their Vulkan clip volume and
  publish exact tested/culled counters. Missing legacy bounds remain visible.
- Project Settings exposes the live rendered-texel budget and compatible-stale-frame
  limit. Atlas resolution is reported there but changes require restart. Per-light
  enable, quality, and priority remain Light component properties.

## Verification

- Debug and Release builds and their complete 67-test suites pass. Architecture tests cover the
  external graph resource/pass, maximum atlas/table capacity, command-line policy,
  and shared deferred/forward shader inclusion.
- Debug Vulkan validation completed without messages for one and two active spot
  owners, including alpha-masked casters.
- A cold two-owner frame updated two 1024 tiles, recorded six caster draws including
  two alpha-mask draws, and measured 0.016640 ms for `gpu.shadow.spot`. Subsequent
  static frames reported two cache hits and zero spot-shadow draws.
- A preliminary single-process 3840x2160 Release sample over 300 static frames
  measured 2.712864 ms median GPU frame time (3.741600 ms p95), 2.019520 ms
  median clustered assignment, and 0.357376 ms median deferred lighting. All measured frames
  were cache hits with zero spot-shadow updates. This is diagnostic evidence, not
  the final multi-process acceptance sample.
- Memory telemetry reports exactly 67,108,864 requested and committed bytes for
  `image.shadow.local` at the default 4096 resolution.
- The deterministic two-color contact capture visibly shows independent orange and
  blue spot projections and shadows. Final-SDR SHA-256:
