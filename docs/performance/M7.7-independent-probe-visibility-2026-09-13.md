# M7.7 independent reflection-probe visibility checkpoint

Date: 2026-09-13  
Status: accepted architecture/correctness slice; device command construction and
scale admission remain open

## Outcome

Reflection captures no longer borrow the main opaque and complex-forward packet
queues as their persistent caster submission. The backend-neutral contract now
accepts a compact list of dense GPU-scene primitive indices selected with
`GpuSceneConsumerProbe`, plus explicit packets only for primitives that could not
enter the persistent publication. Probe membership is therefore camera independent
and remains distinct from main-view and shadow membership.

The Vulkan capture path resolves the compact references from the frame-context CPU
mirror, validates both the primitive and instance probe-consumer masks, and then
performs an independent conservative sphere/frustum test for each scheduled cube
face. Cold primitive identity is mirrored alongside the hot records so the stable
scene owner still excludes the capture probe from its own image. Missing geometry
or material resources remain explicit no-draw failures after visibility; invalid or
stale compact references are counted exactly.

`--reference-direct-gbuffer` now also selects the previous direct packet submission
for probe qualification. It does not alter production behavior.

## Contract and telemetry

- `ReflectionProbeCasterSubmission` is RHI-owned and contains compact GPU-scene
  indices plus direct fallback packets.
- The application publishes probe indices independently of main-view visibility.
- `probe.capture.casters.*` records submitted and resolved compact/direct work,
  invalid compact references, and exact submission bytes.
- `probe.capture.caster_face_tests`, `caster_faces_culled`,
  `caster_face_draws`, and `owner_face_exclusions` describe the actual scheduled
  cube-face work.
- `cpu.render.record.probe_capture` and `gpu.probe.capture` bound capture recording
  and GPU execution when work is scheduled.

## Qualification

The 1280x720 Debug validation fixture used the self-contained M7.7 contact artifact,
the `point_shadow_contact_v1` scene, and `--validate-reflection-probes`. One runtime
capture scheduled six faces over nine opaque primitives:

| Counter | Compact | Direct reference |
|---|---:|---:|
| GPU-scene casters | 9 | 0 |
| Direct packets | 0 | 9 |
| Submission bytes | 36 | 2,160 |
| Resolved casters | 9 | 9 |
| Invalid GPU-scene references | 0 | 0 |
| Caster-face tests / culled / draws | 36 / 3 / 33 | 36 / 3 / 33 |
| Owner-face exclusions | 18 | 18 |
| Final-SDR SHA-256 | `3dd0f02a656888b88e8235bc00733367b4d7d0aaf6c94c9eef3debc8250f1832` | same |

The compact contract reduces submission payload by 60x (98.3333%) in this fixture.
The runtime capture probe is attached to the first renderable model instance, so
three owned primitives across six faces account for the exact 18 exclusions. The
other 36 pairs are independently tested; three are rejected and 33 draw.
Both processes launched, rendered, captured, and exited cleanly under Vulkan
validation. The only console diagnostic was the pre-existing third-party Overwolf
implicit-layer warning; the Vulkan loader skipped that invalid layer.

## Remaining gate

This slice establishes independent membership and compact transport, but capture
draw commands are still recorded directly on the CPU after reference resolution.
M7.7 still owes bounded device-built cube-face commands, probe-specific LOD policy,
warmed heterogeneous update timing, and scale/capacity admission. No ADR is
superseded.
