## Architecture now proven

- Explicit RHI capability reporting covers `multiDrawIndirect`,
  `drawIndirectFirstInstance`, `drawIndirectCount`, and
  `maxDrawIndirectCount`. The RTX 4090 exposes all three features and a
  `UINT32_MAX` command limit.
- `GpuSceneVisibilityAbiVersion` 1 defines conservative Vulkan-frustum extraction,
  coarse instance AABB rejection, exact transformed primitive AABB rejection,
  independent consumer masks, and fail-visible invalid-input behavior.
- `GpuSceneIndirectAbiVersion` 1 mirrors the 20-byte indexed-indirect command ABI.
  It rejects mixed/malformed packets as a complete plan, preserves deterministic
  primitive identity through `firstInstance`, and selects direct submission for
  fewer than eight compatible commands.
- The 240-byte `DrawPacket` ABI is unchanged. One former padding byte now carries
  an execution flag and the existing optional first-instance field carries a GPU-
  scene primitive index only under that flag.
- A dedicated GPU-scene vertex pipeline reconstructs the published row-major 3x4
  transform from `gl_InstanceIndex`. Existing canonical, transparent, shadow, and
  capture vertex paths are unchanged.
- Vulkan groups compatible deferred work by pipeline, material, physical vertex
  and index buffer, vertex offset, and index type. Command/count buffers grow at a
  frame boundary, are fence-owned per frame context, and retain direct fallback for
  capability, capacity, malformed work, tiny work, wireframe, selection, and the
  current complex-forward pass.
- `gpu_scene_frustum_compact.comp` consumes the published transform, instance,
  primitive, and geometry tables, performs exact conservative transformed-AABB
  Vulkan clip tests, atomically compacts one 20-byte indexed command stream per
  deterministic bin, and publishes count buffers directly to
  `vkCmdDrawIndexedIndirectCount`.
- Device commands use the already-bound physical vertex range, so their Vulkan
  `vertexOffset` is zero; the arena's explicit base vertex remains available in
  the geometry table for a later common-arena binding policy without double
  applying an offset.
- Fence-delayed readback attaches exact device-command, CPU-oracle-command,
  mismatched-bin, and overflow counters to the frame that produced them. Push
  constants use published table counts rather than allocation capacities, and
  malformed references never cause an out-of-range shader dereference.
- Caller-owned nonzero observation revisions provide an exact unchanged-scene fast
  path without deep-comparing every primitive each frame. Revisions advance on
  model/geometry/material rebuild, exact transform changes, flags, or consumer-mask
  changes; zero deliberately disables the shortcut for untrusted callers.
- GPU-scene slot retirement uses an intrusive sparse retired-slot chain rather than
  scanning all configured transform, instance, and primitive capacities each
  frame. Collection remains allocation-free, fence-delayed, and generation-safe.
- `gpu_scene.publication.unchanged_fast_path` reports the selected publication
  policy. Scoped CPU ranges separate observation, synchronization, preparation,
  and publication so a capacity scan or deep-comparison regression cannot hide in
  aggregate frame time.
