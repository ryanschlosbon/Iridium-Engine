# M7.5 Topology-Transactional LOD Admission Checkpoint — 2026-09-02

## Decision

Retain the topology-transactional generated-LOD path as experimental and keep LOD0
as the production default. The expanded artifact passes the native-4K static and
temporal fidelity gates with exact device/oracle agreement, but it does not pass the
fresh-process performance gate on the frozen three-asset near/mid/far fixture. At the
2-pixel error ceiling, 2.8282% fewer main-view triangles cost 1.5206% more median wall
time.

This result does not justify loosening geometric error. The measured regression is
selection/compaction overhead rather than raster cost: median GBuffer GPU time is
unchanged, while median GBuffer CPU work rises by 0.0346 ms and GPU compaction rises
by 0.0064 ms. The next admission attempt must first remove qualification-only work
from the deployable path and/or amortize selection over a workload with enough
reducible geometry, then re-run this exact gate. Physical coarser-resident fallback
also remains required before M7.5 completion.

No accepted architecture record changes. ADR-0014's generation-safe publication and
per-content maximum-LOD contracts remain authoritative.

process uses 500 warmup and 10,000 measured frames, validation disabled, CPU/GPU
profiling enabled, and the same experimental LOD/history allocation on both routes.

the cheaper non-experimental production default. NVIDIA telemetry immediately before

## Disposition and next gate

- Keep generated levels, device selection, 15% main-view hysteresis, and the
  per-content maximum-LOD ceiling available only through explicit experimental
  controls.
- Keep production rendering at LOD0; do not claim triangle reduction as a frame-time
  improvement on the current near/mid/far fixture.
- Separate exact CPU-oracle qualification from the deployable selection path, while
  preserving a repeatable parity mode and fail-visible fallback.
- Implement and prove a physical coarser-resident product fallback rather than only
  selecting among already resident parent-contained levels.
- Re-run this same alternating five-process gate after overhead/residency work. A
  production promotion requires non-regressing wall/CPU/GPU distributions and the
  same static/temporal fidelity results.
- Fine-grained texture/geometry/LOD child CookKeys remain M7.9. Independent
  shadow/probe LOD and the recorded directional-shadow fidelity work remain M7.7.

M7.5 remains active. No ADR is superseded and no roadmap slice is accepted by this
checkpoint.

Follow-up: `docs/performance/M7.5-lod-oracle-separation-2026-09-02.md` completes the
qualification/deployable split and repeats the optimized gate. Wall time improves to
effective parity (+0.0378%), but GPU median and tails still regress, so the held
production decision and physical-fallback requirement remain unchanged.
