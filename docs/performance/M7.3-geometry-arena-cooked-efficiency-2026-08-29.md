## Result

M7.3 is accepted. Cooked models now publish one high-precision vertex arena and
separate UInt16/UInt32 index streams through a backend-neutral, versioned range
contract. Stable primitive identity and explicit base-vertex semantics are retained
for classic indexed raster, the M7 GPU scene, future visibility, mesh-shader, and
ray-tracing consumers.

## Architecture and behavior

- `GeometryArenaAbiVersion` is 1. A range is identified by both
  `sourcePrimitiveGuid` and `primitiveGuid`; nil or duplicate identities reject the
  complete arena build.
- Canonical cooked indices remain reconstructable. The planner converts absolute
  source indices to primitive-local indices and carries the primitive's signed
  base-vertex separately. It chooses UInt16 only when every local index fits and
  otherwise uses UInt32.
- Range ordering is independent of source traversal order and deterministic by
  stable identity. Invalid range, index, identity, or integer-width input fails the
  whole build rather than publishing a partial arena.
- Vulkan owns one shared vertex buffer and at most one buffer for each index width.
  Every draw consumer binds the arena's vertex offset; GPU-scene geometry records
  carry the same base vertex. Arena handles retire as one owned allocation set.
- Cooked model schema 6 uses index-section schema 2 (`IRIDXAR1`) with an explicit
  geometry ABI, fixed stable-identity records, and split index streams. Schema-5
  products migrate in memory through the canonical UInt32 representation; unknown
  schema or geometry ABI versions reject explicitly.
- The glTF importer is version 7. Opaque/masked work removes exact cyclic,
  same-winding duplicate triangles and adopts deterministic adjacency-frontier
  reordering only when a 32-entry LRU simulation proves fewer vertex fetches.
  Transparent order is unchanged, and raster and RT reconstruction use the same
  selected triangle order.

## Evaluated candidates

- 3x4 current/previous GPU transforms were already adopted in M7.2: 48 bytes each
  instead of a 64-byte matrix, with exact image parity.
- The 72-byte high-precision standard vertex remains production. Compact positions,
  normals/tangents, and UVs would change the canonical surface-reconstruction input;
  no representative device-fetch evidence yet justifies that fidelity risk. The
  versioned arena permits a later selectable layout.
- A position-only shadow stream would duplicate resident position data before M7.7
  has independent shadow visibility and measured shadow fetch pressure. It is
  deferred to that slice rather than added speculatively.
- The built-in cube and explicit legacy callers retain the single-allocation UInt32
  path. Cooked model assets use the arena path.

## Remaining risk and next boundary

The arena currently allocates whole-model buffers and does not suballocate,
compact, or stream independent primitive children. M7.9 owns progressive physical
residency and fragmentation policy after M7.5 proves LOD products. M7.4 may now
consume stable ranges for frustum visibility and indexed indirect-count submission.

No ADR is added or superseded. ADR-0003's reconstructable geometry contract and
ADR-0006's shared identity/visibility direction remain authoritative.
