# M7.7 warmed reflection-probe LOD admission

Date: 2026-09-24  
Status: qualification gate complete; radial probe LOD remains experimental and
globally default-off

## Outcome

The reflection-sensitive warmed gate is now reproducible, but it does not admit a
production probe-LOD threshold. A standalone non-renderable capture owner lets all
three high-detail Alfa instances contribute to every cubemap face, and its
higher-priority published result drives the glossy main-view surfaces. The fixture
uses a 1024-pixel realtime probe, continuously moving casters, 120 warmup frames,
600 measured frames, and the project-default 30-frame realtime cadence.

The gate exposed a real multi-frame scheduler fault before measurement. Changing
realtime scene revisions invalidated a partially recorded cube without retiring
the backend's ticket-private staging images. The following frame then attempted to
acquire a new ticket for the same owner and failed with `A different capture is
already staged for this probe`. Once a face has been admitted, the scheduler now
finishes and publishes that ticket before observing newer settings or dependency
revisions. This guarantees progress when a cube is spread across frames and keeps
the fence-visible resource lifetime coherent. The next post-publication schedule
observes the latest scene and queues a normal cadence-bounded refresh.

The durable fixture is
`assets/m7-probe-lod-admission-manifest.v1.json` with SHA-256
`ada18ecc957a62a2edf8b462f71bc7126f023235f59106863eca86d49087b57b`.
The benchmark schema now owns the standalone probe position, update mode,
resolution, clip bounds, influence radius, priority, and sky-capture policy.

## Threshold sweep and exactness

The 1024-pixel near-field fixture selects no coarser geometry at the original
2-pixel bound. Short exact-oracle sweeps establish that 8 and 16 pixels produce
small reductions:

| Bound | Retained capture faces | Commands | Capture triangles | Reduced commands |
|---|---:|---:|---:|---:|
| 8 px | 24 | 3,616 | 9,625,536 | 64 |
| 16 px | 24 | 3,616 | 9,573,408 | 136 |

Every sweep has zero mismatched bins, mismatched command regions, overflow
commands, or direct fallback. The full 4K Debug LOD0/16-pixel runs retain the same
512-frame telemetry window and 102 scheduled capture faces:

| Counter | LOD0 | 16 px |
|---|---:|---:|
| Device/oracle commands | 15,368 / 15,368 | 15,368 / 15,368 |
| Device/oracle triangles | 41,067,376 / 41,067,376 | 40,686,984 / 40,686,984 |
| Device/oracle reduced commands | 0 / 0 | 578 / 578 |
| Mismatched bins / command regions | 0 / 0 | 0 / 0 |
| Overflow commands | 0 | 0 |

The 16-pixel candidate removes 380,392 triangles (0.9263%) and changes 578 command
selections (3.7611%). The paired measured-frame final-SDR captures are byte-
identical, both with SHA-256
`00e2d183010d56144eee2e5f2322bf9e5ede44811917e9f14afa2a7007e4216b`.

## Warmed Release timing

Two native-4K, 120-warmup/600-measured-frame Release pairs were run in opposite
order. Each profile contains 120 probe-capture GPU samples and no dropped frames or
CPU/GPU detail overflow.

| Pair/order | Policy | Wall average | Probe GPU median / p95 | Probe CPU median / p95 |
|---|---|---:|---:|---:|
| A first | LOD0 | 4.9998 ms | 0.0463 / 3.0615 ms | 0.0642 / 2.9353 ms |
| A second | 16 px | 5.2645 ms | 0.0477 / 3.2848 ms | 0.0783 / 3.0300 ms |
| B first | 16 px | 4.9030 ms | 0.0481 / 3.2910 ms | 0.0668 / 2.8500 ms |
| B second | LOD0 | 5.0402 ms | 0.0470 / 3.4063 ms | 0.0684 / 2.9689 ms |

The ordering reversal is larger than the geometry saving, and probe CPU/GPU
medians do not establish a repeatable win. The staging and published logical
footprints are unchanged: 142,606,320 and 67,108,848 bytes respectively at the
retained peak.

## Decision

Keep LOD0 as the global reflection-probe default. The face-invariant radial path,
exact oracle, and CLI controls remain available for experimentation, but no
project-facing production threshold is admitted from this content. The gate is
closed rather than left ambiguous: the current high-detail fixture proves visual
stability up to 16 pixels, but its sub-one-percent triangle reduction does not buy
a repeatable CPU, GPU, wall-time, or memory improvement.

Revisit only with a materially different workload, such as distant probe capture
volumes, generated proxy geometry, independent streamed child ranges, or many
simultaneously refreshed high-resolution probes. A future temporal capture design
may freeze one scene snapshot across a distributed six-face ticket; this slice
guarantees lifetime/progress but intentionally does not add that larger mechanism.
