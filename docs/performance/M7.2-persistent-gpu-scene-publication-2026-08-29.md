## Architecture and behavior

- `GpuScenePublisher` owns generation-safe instance, instantiated-primitive, and
  shared-geometry state keyed by stable scene/GUID identities.
- A world epoch change retires all old identities. Ordinary removals use monotonic
  Vulkan submission/completion serials derived from the exact frame fences; a slot
  cannot be reused before its last referencing submission completes.
- Publication preflights each instance atomically. Capacity failure cannot leave
  orphan primitive/geometry records or partially publish an instance.
- Current and previous transforms advance only for actual motion. Instance,
  primitive/material, and geometry revisions remain independently patchable.
- The application retains per-entity primitive extraction and resolved material
  override results. Unchanged entities no longer repeat per-submesh override lookup
  or primitive record construction; transform/bounds refresh uses the cached local
  aggregate bound.
- Vulkan owns four host-visible, coherent storage tables per frame context. Capacity
  grows geometrically at a frame boundary, and each acquired context uploads only
  revision-mismatched contiguous ranges.
- Direct opaque/forward packets are reconstructed from the packed records as the
  M7.2 parity consumer. Transparent packets remain unchanged.

## Scope and remaining risk

- Runtime `RenderInstanceBatchComponent` content deliberately remains direct; its
  authored identity/mobility contract belongs to a later production particle or
  foliage slice.
- M7.2 still stores the current RHI `GeometryHandle` in compatibility geometry
  fields. M7.3 replaces those fields with stable versioned arena ranges.
- Selection state currently changes the instance record. A later visibility slice
  may split it into a smaller independent stream if measurement justifies that.
- This slice proves sparse publication and parity, not visibility or submission
  scaling. Frustum/indirect-count work begins in M7.4 after M7.3 arenas.

No accepted ADR was superseded. ADR-0014 remains the governing publication and
lifetime contract.
