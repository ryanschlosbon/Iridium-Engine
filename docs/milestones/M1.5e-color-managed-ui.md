# M1.5e Acceptance: Color-Managed SDR UI

- Status: Accepted
- Date: 2026-07-22
- Prerequisite: accepted M1.5d production ACES 2 output

## Accepted behavior

Dear ImGui vertex colors are authored as sRGB display colors. The Vulkan backend
uses a custom ImGui fragment shader that decodes only vertex RGB to display-linear
before blending into the sRGB swapchain. Sampled texture RGB is not manually
decoded: sRGB textures receive Vulkan format decode while the UNORM font atlas
remains a linear coverage mask. Alpha remains linear. This prevents double encoding
and keeps UI independent of scene exposure.

`color_volume_transparency_v1` adds deterministic 64/128/192 gray and red/green/blue
authored-sRGB patches after the benchmark viewport image. The overlay is after the
single scene output transform and is not affected by manual scene exposure.

Nsight Graphics 2026.2 also exposed a deprecated device-layer count/pointer pair at
`vkCreateDevice`. Device creation now explicitly uses zero device layers and a null
layer pointer; validation remains correctly enabled at the instance.

## Verification and cost

- Fresh Debug and Release builds pass all 14 CTests in each configuration.
- Shader architecture tests require sRGB decoding of `In.Color.rgb`, forbid manual
  sampled-texture RGB decoding, and retain CPU IEC transfer vectors.
- The complete 4K M0 fixture set plus the M1 color-volume fixture is Vulkan
  validation-clean in graph mode.
- Three 4K Release runs measure UI GPU time at 0.101376 ms median; observed p99 is
  0.107520-0.422912 ms. UI CPU time is 0.0077-0.0081 ms. The earlier shader baseline
  was 0.104448 ms median, so no measurable regression is present.
- Combined median output plus UI GPU time is 0.144384 ms, below the 0.8 ms
  post/output budget. Output plus UI CPU time is about 0.012 ms.
- UI color management adds no persistent or transient image allocation.

M1.5e is accepted. The old pre-placement captures remain diagnostic history and are
not acceptance evidence.
