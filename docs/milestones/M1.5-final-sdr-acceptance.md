## Accepted architecture

M1.5 establishes one explicit final-output boundary after all scene-linear opaque,
emissive, environment, refraction, and transparency composition. Manual exposure is
applied only there. The default Windows path is Rec.709/sRGB SDR through the pinned
Academy ACES 2 transform
`urn:ampas:aces:transformId:v2.0:Output.Academy.Rec709-D65_100nit_in_Rec709-D65_sRGB-Piecewise.a2.v1`
from package `v2.0.0+2025.04.04`.

The production transform is a deterministic 128-cubed log-shaper LUT with
tetrahedral interpolation. `AcesFittedLegacy` remains an explicit compatibility
choice and identity remains diagnostic. Versioned output configuration stores the
operator, requested paper white and peak, manual EV, profile, and metadata policy;
the SDR effective profile is 100-nit Rec.709/sRGB. Scene capture remains linear AP1
PFM, while direct final-SDR capture is BGRA8 sRGB before UI with complete transform
metadata. Display UI is composed afterward through the accepted color-managed path.

## Acceptance results

- Fresh MSVC 19.51 Debug and Release builds pass all 14 CTests in each configuration.
- Debug Vulkan validation passes at 4K for all six required M0 fixtures and
  `color_volume_transparency_v1`, with graph execution and ACES 2 enabled.

- Negative/non-finite handling, monotonic ramps, neutral and hue behavior, operator
  selection, setting bounds/fallback, metadata, exposure-independent scene capture,
  and UI transfer behavior are covered by the accepted test suite.

### Performance and memory

Three 4K Release ACES 2 runs measure the output pass at 0.043008 ms median and at
most 0.044032 ms p99, comfortably below the 0.25/0.35 ms gates. Output CPU time is
0.0042-0.0044 ms, below the 0.02 ms gate. Matched legacy output is 0.028672 ms, so
the production operator adds about 0.0143 ms to output and about 0.0156 ms to GPU
frame time. Combined output plus UI is 0.144384 ms median GPU and about 0.012 ms CPU,
below the 0.8 ms post/output budget.

Total engine memory is 763,463,500 bytes requested and 768,872,128 bytes committed.
The graph accounts for 729,907,200 requested and 735,313,920 committed. The ACES LUT
adds 33,555,968 committed persistent bytes; UI adds none. This is reconciled and
remains materially below the accepted M0 949.220/956.253 MiB target ownership.

## Disposition

Every frozen M1.5 requirement is satisfied. M1.5 is accepted. The rare LUT boundary
maximum remains explicit evidence for future LUT-resolution evaluation; it does not
affect the Academy vector gate or observed color-volume image. M1.6 may now begin
with scRGB negotiation and transport, followed by HDR10/PQ where exposed. M1 itself
remains in progress until M1.6 and the full M1.7 acceptance gate pass.
