# M2.9 - GBuffer Candidate Decision

- Status: Complete
- Accepted: 2026-07-25
- Decision: retain canonical reference R for production

## Candidates

| Candidate | Color bytes/pixel | Key changes |
|---|---:|---|
| R | 36 | Four `RGBA16F` closure targets + `R32_UINT`; complete F90 and 32-bit metadata |
| Q | 26 | octahedral `RG16_SNORM` normal, `B10G11R11` emissive, `R16_UINT`; no F90 |
| C | 18 | Q plus 8-bit diffuse/F0/roughness/AO; no F90 |

R/Q/C are selectable only for controlled experiments through
`--gbuffer-layout reference|quality|compact`. R is the default.

## Image and semantic evidence

All three produced the exact same final-SDR hash on the tracked equivalence fixture:

`ebf0f875122bcc7b16b426df312f49b1e3c10a54a225a1750e3b350aff3de4f4`

That fixture does not exercise non-unit F90 or the upper metadata bits. Q and C
therefore fail a semantic acceptance requirement even though this image is
bit-identical:

- both synthesize F90=1 instead of preserving the compiled scalar;
- both reduce material/feature/closure metadata from 32 to 16 bits;
- C quantizes closure colors and roughness to 8-bit channels.

A packed format cannot be selected while it silently loses accepted closure state.

## Five-run 4K measurements

Each result is the median of five independent Release runs with 500 warm-up and
10,000 measured frames.

| Metric | R | Q | C |
|---|---:|---:|---:|
| GPU frame (ms) | 0.455296 | 0.415712 | 0.394592 |
| GBuffer (ms) | 0.012288 | 0.010240 | 0.008192 |
| deferred lighting (ms) | 0.124928 | 0.099328 | 0.057344 |
| GBuffer + lighting (ms) | 0.137216 | 0.109568 | 0.065536 |
| requested live (MiB) | 861.158 | 608.033 | 608.033 |
| requested peak (MiB) | 893.159 | 640.034 | 640.034 |
| committed live (MiB) | 931.003 | 771.628 | 771.628 |

Q saves 0.027648 ms (20.1%) in the matched pair. C saves 0.071680 ms (52.2%).
C does not reduce graph memory below Q because its additional format split prevents
one physical-slot alias and raises the slot count from nine to ten.

## Decision and rollback

The measured speedups are real, but neither packed candidate preserves the frozen
closure. R remains production and the comparison oracle. Q/C stay isolated
experiments so a later candidate may recover F90 and full metadata while retaining
most of the measured bandwidth benefit. The later visibility-buffer experiment must
compare the full visibility + material resolve + cache + lighting chain against R.
