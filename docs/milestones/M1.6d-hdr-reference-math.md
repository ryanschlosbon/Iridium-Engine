# M1.6d Acceptance: HDR Transport Reference Math

- Status: Accepted
- Date: 2026-07-22
- Runtime behavior change: none

The CPU color reference now defines ST.2084 encode/decode in absolute nits, linear
Rec.2020-to-linear-Rec.709 conversion, Rec.2100-PQ-to-scRGB conversion at 80 nits per
unit, and authored-sRGB UI conversion at configurable paper white. Invalid scale
inputs fail to black; PQ inputs and luminance are bounded to the standard 0-10,000
nit domain while Rec.2020-to-Rec.709 conversion preserves legitimate negative scRGB
components.

`SceneColorTests` passes in Debug and Release with standard 0.1/1/100/1000/10000-nit
PQ vectors, encode/decode round trips, Rec.2020 primary behavior, 203-nit neutral
mapping to 2.5375 scRGB units, and the same mapping for UI white.

This is reference/test code only. Images, frame timing, and memory are unchanged.
The runtime scRGB work is deliberately the next slice so its shader, target formats,
capture semantics, and UI scaling can be checked against this independent oracle.
