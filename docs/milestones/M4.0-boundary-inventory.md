# M4.0 Runtime/Editor Boundary Inventory

Date: 2026-07-31  
Status: Baseline captured before production M4 changes

This inventory freezes the current dependency direction so M4.5 can prove that it
has removed, rather than merely relocated, runtime/editor coupling.

| Runtime-side location | Current editor dependency | Removal owner |
|---|---|---|
| `src/ecs/Registry.h` | `IComponentPool::DrawInspector` and templated calls to component `OnInspector` | M4.5 |
| `src/scene/components/TransformComponent.h` | `editor/Reflection.h`, ImGui-backed property macros, `OnInspector` | M4.5 |
| `src/scene/components/LightComponent.h` | `editor/Reflection.h`, direct ImGui calls, `OnInspector` | M4.5 |
| `src/scene/components/RelationshipComponent.h` | direct `imgui.h` include and direct ImGui calls | M4.5 |
| `src/scene/components/MeshComponent.h` | transitional no-op `OnInspector` required by the pool interface | M4.5 |
| `src/scene/components/NameComponent.h` | transitional no-op `OnInspector` required by the pool interface | M4.5 |
| `src/scene/SceneSerializer.cpp` | central compile-time knowledge of every component type | M4.2-M4.3 |

Current build proof:

- `SceneAssetReferenceTests` must compile four ImGui translation units even though it
  tests scene persistence.
- `TransformSystemTests` must compile the same four ImGui translation units even
  though it tests a runtime ECS system.
- `Registry::getPool<T>()` creates pools during reads and keys them by
  `std::type_index`; Inspector enumeration consequently exposes RTTI names and the
  runtime pool interface.
- `SceneSerializer` includes `scene/Components.h` and contains explicit Transform,
  Mesh, Light, Relationship, and Name branches.

M4.5 completion proof must include a runtime ECS/scene target and focused tests that
compile and link without ImGui, editor panels, native file dialogs, or RTTI-based
drawer discovery.
